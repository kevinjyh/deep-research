# Open Deep Research 專案解析

這是一個 AI 驅動的深度研究助手，能夠對任何主題進行迭代式深入研究。讓我們從用戶角度來了解它的功能：

## 1. 主要功能

### 1.1 研究助手功能
- 輸入任何研究主題
- 自動生成相關搜索查詢
- 分析搜索結果
- 產生詳細的研究報告

### 1.2 互動流程
當用戶啟動程序時（使用 `npm start`），會經歷以下步驟：

1. **初始查詢輸入**
```
What would you like to research? [用戶在此輸入研究主題]
```

2. **研究參數設置**
```
Enter research breadth (recommended 2-10, default 4): [設置研究廣度]
Enter research depth (recommended 1-5, default 2): [設置研究深度]
```
- 廣度：決定每個層級要探索的相關主題數量
- 深度：決定要深入研究的層級數量

3. **追加問題階段**
- 系統會根據初始查詢生成跟進問題
- 用戶需要回答這些問題以幫助系統更好地理解研究需求

4. **研究進度顯示**
在研究過程中，螢幕會顯示即時進度條：
```
Depth:    [██████████████████████] 75%
Breadth:  [███████████████] 50%
Queries:  [██████████] 30%
Current:  正在研究的具體查詢內容
```

5. **最終輸出**
- 生成一個完整的 Markdown 格式報告
- 自動保存為 `output.md` 文件
- 包含所有研究發現和參考來源

## 2. 進度追蹤系統

### 2.1 進度條顯示
- **深度進度**：顯示研究深入程度
- **廣度進度**：顯示橫向研究覆蓋範圍
- **查詢進度**：顯示已完成的搜索查詢數量
- **當前任務**：顯示正在處理的具體查詢

### 2.2 即時更新
- 進度條會實時更新
- 使用動態刷新，不會干擾其他輸出內容
- 清晰顯示研究進展

## 3. 最終報告格式

報告通常包含以下部分：
- 研究主題概述
- 主要發現
- 深入分析
- 相關數據和統計
- 參考來源列表

## 4. 使用案例示例

假設用戶想研究"人工智能在醫療診斷中的應用"：

1. **輸入階段**
```
What would you like to research? 人工智能在醫療診斷中的應用
Enter research breadth: 4
Enter research depth: 2
```

2. **跟進問題可能包括**：
- 您對特定醫療領域特別感興趣嗎？
- 您是否需要關注特定的AI技術？
- 您是否需要包含成本效益分析？

3. **研究過程**
- 系統會自動搜索相關文獻
- 分析醫療AI應用案例
- 整理研究發現
- 生成綜合報告

## 5. 技術特點（用戶視角）

- **智能查詢生成**：自動創建相關搜索詞
- **深度分析**：逐層深入研究主題
- **並行處理**：同時處理多個搜索和分析任務
- **自適應研究**：根據初始結果調整研究方向
- **全面報告**：生成結構化的研究報告

## 6. 使用建議

1. **研究主題**：
   - 盡可能具體
   - 清晰表達研究目標
   - 提供足夠的背景信息

2. **參數選擇**：
   - 廣度(2-10)：影響研究範圍
   - 深度(1-5)：影響研究細節程度

3. **跟進問題**：
   - 詳細回答系統提出的問題
   - 提供具體的研究方向偏好
   - 說明特定的關注點

這個工具特別適合：
- 學術研究初期調研
- 市場分析
- 技術趨勢研究
- 競爭對手分析
- 新領域探索
